# Лабораторна робота №6: Об'єктно-орієнтоване проєктування чисельних методів інтегрування в Python

## Задача: Обчислити визначений інтеграл із заданою точністю трьома способами (складеними квадратурними формулами середніх прямокутників, трапецій та Сімпсона), визначивши для кожного мінімальну кількість розбиттів за правилом Рунге з уточненням за екстраполяцією Річардсона. Дослідити поведінку методів при зменшенні точності у 10 разів
### Варіант завдання 7: I = integral from 0 to 1 (sin(x + x^3)dx), E = 0.00005

## Структура проєкту:
* 'integrators.py' - модуль із реалізацією ієрархії класів, атрибутів класів, методів @classmethod i @staticmethod, магічного методу '__str__' та адаптивного алгоритму.
* 'main.py' - головний виконуваний модуль із підінтегральною функцією, запуском обчислень і виводом/збереженням результатів

## Інструкція запуску:
1. Клонувати репозиторій:
   git clone https://github.com/daryna-zembovych/lab-oop-numerical-integration
2. Перейдіть до його каталогу:
   cd lab-oop-numerical-integration
3. Запустіть головний модуль:
   python main.py
